Operation chain (all in the decode direction):
 
1. Substitution - decode
   Ciphertext uses only the letter A or a with three different accent marks,
   in groups of three. Replace each mark with a letter:
     caron -> A
     inverted breve below -> B
     breve below  -> C
 
 
2. Triliteral cipher - decode (dCode Triliteral Cipher, AAA=A, AAB=B,... )
   Each group of three becomes one letter.
 
3. Fractionated Morse cipher - decode, no key uses standard alphabet
   (dCode "Fractionated Morse Cipher")
   Each letter becomes three Morse symbols (dot, dash, or separator x).
 
4. Morse code - decode (x = letter break, xx = word break)
    
5. Vigenere cipher - decode, key "rick"
